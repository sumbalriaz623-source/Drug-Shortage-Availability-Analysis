# Drug Shortage Availability Analysis

## Pharmaceutical Data Analysis Using FDA Open Data

This project analyzes real-world drug shortage records from the U.S. Food and Drug Administration (FDA) openFDA Drug Shortages API.

The analysis explores drug shortages by status, shortage reason, therapeutic category, pharmaceutical company, and dosage form.

## Objectives

- Analyze real-world FDA drug shortage records
- Identify common shortage reasons
- Explore affected therapeutic categories
- Examine companies represented in shortage records
- Analyze dosage forms involved in shortages
- Create visualizations to communicate pharmaceutical supply trends
- Produce a cleaned dataset for further analysis

## Dataset

The project analyzes 100 FDA drug shortage records.

The dataset includes information such as:

- Generic drug name
- Brand name
- Company
- Shortage status
- Shortage reason
- Therapeutic category
- Dosage form
- Initial posting date
- Update date

## Methodology

1. Retrieved drug shortage records using the FDA openFDA API.
2. Loaded the records into Python using Pandas.
3. Examined the available variables.
4. Analyzed shortage status and shortage reasons.
5. Explored therapeutic categories, companies, and dosage forms.
6. Created visualizations to summarize the data.
7. Generated a cleaned CSV dataset.
